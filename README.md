# Star Wars Character Data Fetcher

This project is designed to fetch data about Star Wars characters from a website and present it in a structured format. The data includes various attributes of the characters such as their name, family, character type, species, masters, and apprentices.

## Features
- Fetches data from a specified website.
- Structures the data using Pydantic models.
- Supports various character types including Jedi, Sith, Droid, and Other.

## Installation
1. Clone the repository.
2. Install the required dependencies using `pip install -r requirements.txt`.

## Usage
Run the main script to fetch and display the character data.
